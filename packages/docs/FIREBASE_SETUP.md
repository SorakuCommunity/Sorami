## 📱 How to Use in the App
The Firebase app is initialized in `main.dart`:
```dart
Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  if (defaultTargetPlatform != TargetPlatform.linux) {
    await Firebase.initializeApp(
      options: DefaultFirebaseOptions.currentPlatform,
    );
  }
  runApp(const ProviderScope(child: SoramiApp()));
}
```

## 📝 Note on Architecture
The current Sorami architecture plans to use a REST API with NestJS backend. Firebase is being used here primarily for:
- Authentication (as an alternative/custom option)
- Cloud Messaging for push notifications
- Potentially other Firebase services as needed

If the decision is to use Firebase as the primary backend, then the NestJS API would be replaced or supplemented with Firebase services. However, based on the original techspec, Firebase is listed alongside the NestJS API, suggesting it's for specific services like messaging and possibly authentication.
